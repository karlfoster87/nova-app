            Claude sign-in

            Nova keeps its own sign-in, separate from any Claude Code on this machine, and renews it while it runs. A Claude subscription shows plan usage in the header. An Anthropic Console account bills the API instead and has no usage bars.

            1. Open the sign-in page in any browser and approve Nova.

            2. Copy the code the page shows and paste it here.

            Brain folder

            The folder Claude works from. Its CLAUDE.md and .claude settings load into every chat, and profile notes live in its profiles folder.

            Saving restarts Nova, which closes open chats. Chats and categories belong to the brain folder they were made in: after the switch you'll see the new folder's, and switching back brings these back.

            Defaults

            A summary of Claude's reasoning streams into each reply's Thinking block. It costs nothing extra, since the thinking happens either way. Open chats switch over once they finish what they're doing.

            Nova

            Nova updates itself from GitHub. An update is downloaded into a staging folder and tested there first. Nova then restarts to install it, and goes back to this version if the new one fails to install or to start. A copy with changes that aren't on GitHub yet is never updated.

            Claude Agent SDK

            Nova talks to Claude through this package. Updating installs the new version into a staging folder and tests it first. Nova restarts only if the test passes, and open chats close when it does. Nova never updates by itself.
